# 🛸 NEXORA — Autonomous Robotics & Drone E-Commerce Platform

> **Make in India • DGCA Type-Certified Series**  
> Next-generation web application for autonomous aerial drones, bionic mechs, AI perception LiDAR sensors, and custom UAV customizer studio.

---

## 🌟 Key Features

- **🇮🇳 Indian Localization & Rupee (₹) Pricing**: Full catalog formatted in Indian Rupees (`₹`), DGCA Drone Rules 2021 compliance, and NavIC satellite positioning.
- **🛸 Hardware Catalog & Filtering**: 8K LiDAR Cinema Drones, 160km/h FPV Racers, Quadruped Mechs, Amphibious Air/Water Drones, AI LiDARs, and Bionic Manipulators.
- **⚙️ Custom Drone Studio (Configurator)**: Step-by-step modular builder for airframes, propulsion, camera payloads, and AI flight computers with real-time telemetry (flight time, all-up mass, agility score, total price).
- **🔬 360° Hardware Spec Inspector**: Interactive 360° model rotation controls, key capability breakdown, in-the-box manifest, and operator reviews.
- **📊 Side-by-Side Comparison Matrix**: Compare up to 4 models simultaneously across flight endurance, velocity, sensor arrays, AI compute power, and payload capacity.
- **🛒 Cart & Indian Checkout**: Slide-out cart drawer with *Nexora Care+* warranty add-on (+2 Yrs coverage), coupon engine (`INDIA10`, `NEXORA20`), and Indian checkout supporting **UPI (Google Pay, PhonePe, Paytm, BHIM)**, Cards, and NetBanking.
- **🏢 Dedicated About Us Page**: Highlights Nexora's Bengaluru R&D campus, Hyderabad autonomous test range, and Pune aerodynamics facility.
- **🧠 Nexora India AI Product Advisor**: Interactive chatbot widget providing contextual hardware recommendations based on project requirements.

## 🚀 Quick Start

### 1. Clone & Install Dependencies
```bash
git clone https://github.com/<YOUR_USERNAME>/nexora.git
cd nexora
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

### 3. Build for Production
```bash
npm run build
```
